# Свои персонажи

Создайте здесь папку на каждого персонажа и положите в неё модель (FBX/OBJ/DAE или .prefab),
анимации (Idle / Walking / Running / Jump / Falling) и, по желанию, `character.json`.
Папки, имя которых начинается с `_` или `.`, пропускаются.

Подробности — в README.md в корне репозитория.
