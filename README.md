# Character Playground (Unity 6)

Сцена для просмотра персонажей и съёмки видео: персонажи стоят на чистой сцене и показывают
на месте покой, шаг, бег или прыжок, а камера свободно летает вокруг — пальцами на телефоне
или мышью на компьютере.

Unity запускается в облаке без окна (Docker-образ GameCI), собирает сцену в WebGL,
и сборку можно открыть как обычную веб-страницу — на компьютере или телефоне.

## Что есть в сцене

- **Сцена**: пол с сеткой 1×1 м, чтобы сравнивать размеры.
- **Свои персонажи** из `Assets/Characters` (см. ниже) — идут первыми. Сейчас там Бекон (аватар из Roblox).
- **Встроенные персонажи** с разными пропорциями: Рыцарь, Скаут, Голем, Прыгун.
- **Все на сцене / Только этот** — все персонажи в ряд с подписанным ростом или один выбранный.
- **Анимация** выбранного персонажа: Покой, Шаг, Бег, Прыжок — на месте, без перемещения.
- **Скрыть меню** — убирает меню, подсказку, подписи и FPS, чтобы кадр был чистым.

## Управление

| Телефон | Компьютер |
|---|---|
| 1 палец — вращать камеру вокруг | левая кнопка мыши — вращать |
| 2 пальца — двигать камеру | правая или средняя кнопка (или Shift + левая) — двигать |
| щипок — приблизить / отдалить | колесо — зум |
| поворот двух пальцев — крутить вокруг | — |
| двойной тап — вернуться к персонажу | двойной клик или F |
| долгое нажатие — вернуть скрытое меню | H — показать / скрыть меню |
| `<` `>` в меню — выбрать персонажа | Tab, `[` `]` или 1–9 |
| | L — все на сцене / только этот |

## Как добавить своего персонажа

Одна папка — один персонаж:

```
Assets/Characters/
  Knight/
    Knight.fbx          модель (FBX, OBJ, DAE или готовый .prefab)
    Idle.fbx            анимации — по названию файла или клипа:
    Walking.fbx           idle / walk / run (sprint, jog) / jump / fall
    Running.fbx
    Jump.fbx
    Falling.fbx
    character.json      необязательно: настройки
```

Удобный источник — [Mixamo](https://www.mixamo.com): модель скачать как *FBX for Unity, With Skin*,
анимации — тоже FBX, для ходьбы и бега включить **In Place**.

При сборке (`Playground → Prepare Project` в редакторе или `tools/unity.sh build`) импортёр сам:
настраивает скелет (Humanoid, если получится, иначе Generic), зацикливает idle/walk/run,
собирает Animator Controller и кладёт префаб в `Assets/Resources/Characters`.

`character.json` (все поля необязательные):

```json
{
  "displayName": "Рыцарь",
  "walkSpeed": 3,
  "runSpeed": 6,
  "jumpHeight": 1.2,
  "gravity": 20,
  "height": 1.8,
  "yawOffset": 0
}
```

`walkSpeed` и `runSpeed` (м/с) задают темп шага и бега на месте, `jumpHeight` (м) и `gravity` (м/с²) —
высоту и резкость прыжка. `height` — привести модель к этому росту в метрах (0 — оставить как есть;
модели в сантиметрах масштабируются автоматически). `yawOffset` — повернуть модель, если она смотрит
не вперёд (+Z); модели из Roblox смотрят назад, им нужно `180`.

### Модель из отдельных частей (Roblox и похожие)

Если у модели нет скелета, но тело собрано из отдельных кусков (так экспортирует Roblox Studio через `Export Selection`:
в `.obj` части называются, например, `Rig1`…`Rig15`), её можно оживить без анимаций: перечислите в `segments`, какая часть чем
является. Импортёр соберёт суставы — поясницу, шею, плечи, локти, бёдра и колени — и персонаж будет ходить, бегать
и прыгать процедурно. Кисти и ступни двигаются вместе с предплечьем и голенью, волосы и шапки впишите в `head`.
Пример — `Assets/Characters/Bacon/character.json`:

```json
{
  "yawOffset": 180,
  "height": 1.6,
  "segments": {
    "head": "Rig10, Handle1",
    "upperTorso": "Rig15",
    "lowerTorso": "Rig14",
    "leftUpperArm": "Rig9",  "leftLowerArm": "Rig8",  "leftHand": "Rig7",
    "rightUpperArm": "Rig13", "rightLowerArm": "Rig12", "rightHand": "Rig11",
    "leftUpperLeg": "Rig6",  "leftLowerLeg": "Rig5",  "leftFoot": "Rig4",
    "rightUpperLeg": "Rig3", "rightLowerLeg": "Rig2", "rightFoot": "Rig1"
  },
  "colors": [
    { "parts": "Rig10, Rig7, Rig11", "color": "#F5CD30" },
    { "parts": "Handle1", "color": "#7B4A2A" }
  ]
}
```

Если не знаете, какая часть какая, соберите проект: для модели без анимаций импортёр выводит в лог
список частей с их положением (сверху вниз). Левую и правую сторону он при необходимости меняет местами сам.

`colors` красит части в цвет `#RRGGBB` — пригодится, если `.obj` пришёл без `.mtl` и текстур.
Если положить `.mtl` и текстуры из экспорта рядом с `.obj`, Unity попробует взять цвета из них.

Если у персонажа свой Animator Controller, `PlayableCharacter` передаёт в него параметры
`Speed` (0 — стоит, 1 — идёт, 2 — бежит), `MoveSpeed` (м/с), `Grounded`, `VerticalSpeed` и триггер `Jump` —
используются только те, что есть в контроллере.

## Запуск в облаке (Claude Code)

```bash
tools/unity.sh compile   # проверить, что C# компилируется (лицензия не нужна)
tools/unity.sh build     # собрать WebGL в Build/WebGL
```

Скрипт сам поднимает Docker, скачивает образ `unityci/editor:ubuntu-6000.0.84f1-webgl-3` (~7.5 ГБ)
и запускает Unity без окна. Unity требует лицензию даже в таком режиме — её берут из переменных окружения:

- **Unity Personal** (бесплатная): `UNITY_EMAIL` и `UNITY_PASSWORD` от аккаунта Unity.
  На каждый запуск скрипт берёт место лицензии через Unity Licensing Client
  (`--activate-all --include-personal`) и возвращает его после сборки.
  Файл `.ulf` для Personal больше не выдаётся — Unity отключил ручную активацию.
  Если вход в Unity через Google/Apple, задайте пароль аккаунта на https://id.unity.com.
- **Unity Pro / Plus**: дополнительно `UNITY_SERIAL`.
- **Готовый `.ulf`** (Enterprise или старые активации): `UNITY_LICENSE` — содержимое файла как есть или в base64.

Сеть окружения должна пускать к серверам Unity: `core.cloud.unity3d.com`, `license.unity3d.com`,
`activation.unity3d.com`, `public-cdn.cloud.unity3d.com`, `cdp.cloud.unity3d.com`,
`api.unity.com`, `login.unity.com`.

## Локально

Откройте папку в Unity Hub (редактор **6000.0.84f1** или любой Unity 6), выполните
`Playground → Prepare Project`, откройте `Assets/Scenes/Playground.unity` и нажмите Play.
