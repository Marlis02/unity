# Character Playground (Unity 6)

Песочница для тестирования персонажей: бегаешь персонажем по полигону прямо в браузере,
меняешь его характеристики ползунками и сравниваешь персонажей между собой.

Unity запускается в облаке без окна (Docker-образ GameCI), собирает сцену в WebGL,
и сборку можно открыть как обычную веб-страницу — на компьютере или телефоне.

## Что есть в сцене

- **Полигон**: пол с сеткой 1×1 м, блоки для проверки высоты прыжка (0.5–3 м),
  платформы с промежутками для дальности прыжка (1–6 м), лестницы со ступенями 0.2 и 0.4 м,
  уклоны 20°/35°/50°, проходы высотой 2.6/2.0/1.6/1.2 м и ящики/мячи, которые можно толкать.
- **Встроенные персонажи** с разными пропорциями и характеристиками: Рыцарь, Скаут, Голем, Прыгун.
- **Свои персонажи** из `Assets/Characters` (см. ниже) — идут в списке первыми.
- **Панель**: скорость, рост, высота последнего прыжка; ползунки ходьбы, бега, прыжка,
  гравитации, поворота, разгона, управления в воздухе и скорости времени (замедление).
- **Строй** — остальные персонажи встают в ряд с подписанным ростом для сравнения.

## Управление

| Компьютер | Телефон |
|---|---|
| WASD / стрелки — идти | левая половина экрана — джойстик |
| Shift — бег | кнопка «Бег» (переключатель) |
| Пробел — прыжок | кнопка «Прыжок» |
| мышь с зажатой кнопкой — камера, колесо — зум, Q/E — поворот | правая половина экрана — камера |
| Tab или 1–9 — сменить персонажа | кнопки `<` `>` на панели |
| R — на старт, L — строй, P — настройки, H — подсказка | кнопки на панели |

## Как добавить своего персонажа

Одна папка — один персонаж:

```
Assets/Characters/
  Knight/
    Knight.fbx          модель (FBX, OBJ, DAE или готовый .prefab)
    Idle.fbx            анимации — по названию файла или клипа:
    Walking.fbx           idle / walk / run (sprint, jog) / jump / fall
    Running.fbx
    Jump.fbx
    Falling.fbx
    character.json      необязательно: характеристики
```

Удобный источник — [Mixamo](https://www.mixamo.com): модель скачать как *FBX for Unity, With Skin*,
анимации — тоже FBX, для ходьбы и бега включить **In Place**.

При сборке (`Playground → Prepare Project` в редакторе или `tools/unity.sh build`) импортёр сам:
настраивает скелет (Humanoid, если получится, иначе Generic), зацикливает idle/walk/run,
собирает Animator Controller, подбирает размер капсулы и кладёт префаб в `Assets/Resources/Characters`.

`character.json` (все поля необязательные):

```json
{
  "displayName": "Рыцарь",
  "walkSpeed": 3,
  "runSpeed": 6,
  "jumpHeight": 1.2,
  "gravity": 20,
  "turnSpeed": 720,
  "airControl": 0.4,
  "acceleration": 30,
  "height": 1.8,
  "yawOffset": 0
}
```

`height` — привести модель к этому росту в метрах (0 — оставить как есть; модели в сантиметрах
масштабируются автоматически). `yawOffset` — повернуть модель, если она смотрит не вперёд (+Z).

Если у персонажа свой Animator Controller, `PlayableCharacter` передаёт в него параметры
`Speed` (0 — стоит, 1 — идёт, 2 — бежит), `MoveSpeed` (м/с), `Grounded`, `VerticalSpeed` и триггер `Jump` —
используются только те, что есть в контроллере.

## Запуск в облаке (Claude Code)

```bash
tools/unity.sh compile   # проверить, что C# компилируется (лицензия не нужна)
tools/unity.sh build     # собрать WebGL в Build/WebGL
```

Скрипт сам поднимает Docker, скачивает образ `unityci/editor:ubuntu-6000.0.84f1-webgl-3` (~7.5 ГБ)
и запускает Unity без окна. Unity требует лицензию даже в таком режиме — её берут из переменных окружения:

- **Unity Personal** (бесплатная): `UNITY_EMAIL` и `UNITY_PASSWORD` от аккаунта Unity.
  На каждый запуск скрипт берёт место лицензии через Unity Licensing Client
  (`--activate-all --include-personal`) и возвращает его после сборки.
  Файл `.ulf` для Personal больше не выдаётся — Unity отключил ручную активацию.
  Если вход в Unity через Google/Apple, задайте пароль аккаунта на https://id.unity.com.
- **Unity Pro / Plus**: дополнительно `UNITY_SERIAL`.
- **Готовый `.ulf`** (Enterprise или старые активации): `UNITY_LICENSE` — содержимое файла как есть или в base64.

Сеть окружения должна пускать к серверам Unity: `core.cloud.unity3d.com`, `license.unity3d.com`,
`activation.unity3d.com`, `public-cdn.cloud.unity3d.com`, `cdp.cloud.unity3d.com`,
`api.unity.com`, `login.unity.com`.

## Локально

Откройте папку в Unity Hub (редактор **6000.0.84f1** или любой Unity 6), выполните
`Playground → Prepare Project`, откройте `Assets/Scenes/Playground.unity` и нажмите Play.
